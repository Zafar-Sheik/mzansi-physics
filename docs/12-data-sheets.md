# Data sheets: constants & formulas

These follow the NSC Physical Sciences data sheets. Learners get them in the exam, so they don't have to memorise the formulas. They do have to know **when** to use each one. The interactive version is in the Toolkit (*Data sheets*), with the periodic table and the table of standard reduction potentials.

## Motion

$$v_f = v_i + a\Delta t \qquad \Delta x = v_i\Delta t + \tfrac12 a\Delta t^2$$

$$v_f^2 = v_i^2 + 2a\Delta x \qquad \Delta x = \left(\frac{v_i + v_f}{2}\right)\Delta t$$

## Force

$$F_{net} = ma \qquad p = mv \qquad F_{net}\Delta t = \Delta p = mv_f - mv_i$$

$$w = mg \qquad f_s^{max} = \mu_s N \qquad f_k = \mu_k N \qquad F = \frac{Gm_1m_2}{r^2} \qquad g = \frac{GM}{r^2}$$

## Work, energy & power

$$W = F\Delta x\cos\theta \qquad E_p = mgh \qquad E_k = \tfrac12 mv^2$$

$$W_{net} = \Delta E_k \qquad W_{nc} = \Delta E_k + \Delta E_p \qquad P = \frac{W}{\Delta t} \qquad P_{ave} = Fv_{ave}$$

## Waves, sound & light

$$v = f\lambda \qquad T = \frac1f \qquad f_L = \frac{v \pm v_L}{v \pm v_s}f_s \qquad E = hf = \frac{hc}{\lambda}$$

$$E = W_0 + E_{k(max)} \qquad W_0 = hf_0 \qquad n = \frac{c}{v} \qquad n_1\sin\theta_1 = n_2\sin\theta_2$$

## Electrostatics

$$F = \frac{kQ_1Q_2}{r^2} \qquad E = \frac{kQ}{r^2} \qquad E = \frac{F}{q} \qquad V = \frac{W}{q} \qquad n = \frac{Q}{e}$$

## Electric circuits & electrodynamics

$$R = \frac{V}{I} \qquad \varepsilon = I(R + r) \qquad R_s = R_1 + R_2 + \dots \qquad \frac{1}{R_p} = \frac{1}{R_1} + \frac{1}{R_2} + \dots$$

$$q = I\Delta t \qquad W = Vq = VI\Delta t = I^2R\Delta t \qquad P = VI = I^2R = \frac{V^2}{R}$$

$$\varepsilon = -N\frac{\Delta\Phi}{\Delta t} \qquad \Phi = BA\cos\theta \qquad I_{rms} = \frac{I_{max}}{\sqrt2} \qquad V_{rms} = \frac{V_{max}}{\sqrt2}$$

$$P_{ave} = V_{rms}I_{rms} = I_{rms}^2R = \frac{V_{rms}^2}{R}$$

## Chemistry formulas

$$n = \frac{m}{M} \qquad n = \frac{N}{N_A} \qquad c = \frac{n}{V} \qquad c = \frac{m}{MV} \qquad n = \frac{V}{V_m}$$

$$\frac{c_aV_a}{c_bV_b} = \frac{n_a}{n_b} \qquad \text{pH} = -\log[\mathrm{H_3O^+}] \qquad K_w = [\mathrm{H_3O^+}][\mathrm{OH^-}] = 1 \times 10^{-14} \text{ at } 298\ \text{K}$$

$$E^\theta_{cell} = E^\theta_{cathode} - E^\theta_{anode} \qquad \frac{p_1V_1}{T_1} = \frac{p_2V_2}{T_2} \qquad pV = nRT \quad (R = 8{,}31\ \text{J·K}^{-1}\text{·mol}^{-1})$$
